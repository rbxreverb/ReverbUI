# ReverbUI

> Legacy UI library. Reverb J is now the preferred and primary UI for new Reverb
> scripts because of its simpler, more compact design. Keep ReverbUI available for
> existing scripts that still depend on it, but do not use it as the default for
> new work.

Personal legacy UI library for Reverb projects.

Runtime entry:

```lua
local ReverbLib = loadstring(game:HttpGet("https://raw.githubusercontent.com/rbxreverb/ReverbUI/refs/heads/main/source.lua"))()
```

This repository contains the public runtime files required for the interface.
